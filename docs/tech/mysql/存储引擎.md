# MySQL 存储引擎

## MySQL 体系结构

- 连接层
  - 连接池
- 服务层
  - SQL接口，解析器，查询优化器，缓存
- 引擎层
  - InnoDB，NDB，MyISAM等存储引擎
- 存储层
  - 系统文件、文件和日志


### 连接层

在MySQL体系结构中处于最上层，主要负责与客户端的链接服务，处理权限认证，分配连接池等功能


### 服务层

服务层是整个MySQL体系中负责最多功能的一层结构，包括SQL接口，处理SQL语句，优化SQL语句，分析SQL，部分内置函数的执行等


### 引擎层

这一层主要负责MySQL与真实物理数据的交互，服务器通过API和存储引擎进行通信


### 存储层

存储层很简单直接，就是与操作系统的文件系统打交道，完成存储引擎和系统文件的交互


## 存储引擎

> 存储引擎就是存储数据，建立索引，更新\查询数据等技术的实现方式。存储引擎是基于表的，而不是基于库的。

```sql
CREATE TABLE `test` (
  `id` int NOT NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci
```

**MySQL 默认的存储引擎就是 InnoDB**


> 查看当前数据库支持哪些存储引擎

```sql
show engines;
```


## 存储引擎特点

- InnoDB - 兼顾可靠性和高性能的通用存储引擎，在MySQL5.5之后，InnoDB是默认的MySQL存储引擎
  - DML遵循ACID模型（一致性、原子性、持久性、隔离性），支持事务
  - 行级锁
  - 支持外键
  - xxxx.idb （InnoDB引擎的每张表都对应一个这样的表空间文件，存储表结构，数据，索引）
  - 段页式存储
- MyISAM - MySQL早期的默认存储引擎
  - 不支持事务
  - 不支持外键
  - 最小支持表锁
  - 访问速度很快
  - xxxx.sdi xxx.MYD xxx.MYI
- Memory - 内存存储数据，一般作为临时表
  - 内存存放
  - hash索引
  - xxx.sdi 存储表结构等信息
